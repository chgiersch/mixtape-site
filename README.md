# mixtape-site

The published copies of Mixtape: Music Tree pages, one folder per pair of
friends (`<a>-<b>/`). In each, `index.html` is the viewer and the `.enc`
files are that pair's listening histories, encrypted in the browser's own
AES-GCM with a key derived from a passphrase the pair was told in person.
Nothing here opens without it, and each passphrase opens one folder only.

Generated by the pipeline in the (local-only) mixtape repo; do not edit by
hand. Pages serves `main` from the root; a pair's page is at
`/mixtape-site/<a>-<b>/`. The root itself holds no page.
